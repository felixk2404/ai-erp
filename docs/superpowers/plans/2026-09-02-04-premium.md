# AI-ERP — תוכנית 4: פרמיום (דשבורד חכם, שירות לקוחות באתר, תמונות AI, אנימציות ועמודי פרט)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** להעלות את האפליקציה מ"נכון" ל"מעוצב ומועיל": דשבורד עם גרפים, תקציר AI ורשימת דורש-טיפול; שירות לקוחות (סוכן ה-RAG) בתוך האתר בעמוד ציבורי ובוידג'ט; תמונות מוצר, לוגו ואיורים שנוצרו ב-AI; אנימציות מעברים וכניסות; עמודי פרט לחשבונית וללקוח; חיפוש ⌘K.

**Architecture:** אותה ארכיטקטורה (Server Components ← Airtable, Server Actions → n8n). תוספות: (1) WF5-core sub-workflow שמשרת גם טלגרם וגם `WF13 action:"support"`; (2) Supabase Storage bucket ציבורי `assets` לתמונות מוצר, שדה `ImageUrl` חדש ב-Products; (3) n8n Public API נקרא מהשרת (health); (4) Motion + React View Transitions לאנימציות; Recharts לגרפים (גוון יחיד + פלטת סטטוס — הפלטה הקטגוריאלית נכשלה ב-validator).

**Tech Stack:** motion 13, recharts 3, cmdk 1.1, React ViewTransition (Next 16 flag), fal.ai `fal-ai/nano-banana-2` ($0.08/תמונה), Supabase Storage REST, Airtable Metadata API.

**Spec:** `docs/superpowers/specs/2026-09-02-ai-erp-design.md` + כיוון עיצובי ב-`app/.interface-design/system.md`

## Global Constraints

- הכל מה-system.md: paper/ink/inkblue, LED לסטטוס, Plex + Frank Ruhl, 8px, borders-only. אף hex חדש בקומפוננטות — רק טוקנים.
- גרפים (dataviz): גוון יחיד `--inkblue` לסדרה אחת; ריבוי סטטוסים → פלטת LED עם תוויות ישירות + legend; marks דקים, 2px רווח, tabular-nums, tooltip. אין dual-axis, אין קטגוריאלי >1 גוון.
- אנימציות: < 300ms, ease-out, `transform`/`opacity` בלבד, `MotionConfig reducedMotion="user"`, View Transitions עם `default="none"` בעמודים.
- כל הודעה מהסוכנים מוצגת כטקסט; escape נעשה על ידי React.
- עמוד `/support` ציבורי (ללא סיסמה) — rate limit בסיסי בשרת: 20 הודעות/דקה ל-IP (Map בזיכרון; ponytail: מספיק לדמו). הודעות עד 500 תווים.
- תמונות: WebP, 1024px, שמות `products/<slug>.webp`. נשמרות ב-Supabase Storage (public) — ה-URL ב-Airtable `ImageUrl`. נכסי מותג (לוגו, hero, איורים) ב-`app/public/brand/` ב-git.
- שמות שדות חדשים: Products.ImageUrl (url). כל השאר ללא שינוי.
- סודות: `N8N_API_URL`, `N8N_API_KEY` (אופציונליים; בלעדיהם ווידג'ט הבריאות מציג "לא מחובר"). הסטודנט מוסיף ל-.env.local ול-Vercel (`scripts/vercel-env.sh`).
- TDD ל-lib (charts data shaping, attention rules, rate limit, product matching). Playwright לכל מסך חדש.

### Task 2: נכסים — bucket, שדה ImageUrl, יצירת תמונות

**Files:** `n8n/scripts/supabase-storage.sh` (יוצר bucket `assets` public דרך REST), `airtable/add-image-field.sh`, `app/scripts/assets/products.json` (פרומפטים), `app/scripts/assets/upload.sh` (מעלה מ-URL ל-Storage וכותב ImageUrl ל-Airtable), `app/public/brand/{logo.svg|png, hero.webp, empty-*.webp}`.

- Bucket: `POST $SUPABASE_URL/storage/v1/bucket {"id":"assets","name":"assets","public":true}` עם service key. Upload: `POST /storage/v1/object/assets/<path>` (Content-Type image/webp, `x-upsert: true`). URL: `$SUPABASE_URL/storage/v1/object/public/assets/<path>`.
- Airtable: `POST /meta/bases/{base}/tables/{tblProducts}/fields {"name":"ImageUrl","type":"url"}`. types.ts: `ImageUrl?: string`.
- תמונות מוצר (34): fal `fal-ai/nano-banana-2`, prompt אחיד: *"Studio product photograph of {name} — {short english description}. Single product, centered, three-quarter view, on a seamless warm cream background (#f3eee3), soft diffused daylight from the upper left, gentle contact shadow, brushed-aluminium and matte-anthracite materials, no text, no logos, no people, photorealistic, e-commerce catalog quality."* `aspect_ratio:"1:1"`, `resolution:"1K"`, `output_format:"webp"`. ההרצה דרך fal MCP מהסשן; התוצאות (URL) → `upload.sh` מוריד ומעלה ל-Storage ומעדכן Airtable.
- לוגו: nano-banana-2, *"Minimal flat logo mark for an Israeli electronics retailer named AI Electronics: an open invoice book whose lines turn into a circuit trace, carbon-blue (#2b4c7e) on cream (#f7f3ea), geometric, no text, centered, generous margins"* → PNG → `public/brand/logo.png` (+ favicon). Hero ל-login: *"Editorial still life on a warm wooden workshop desk: a paper invoice book with a blue carbon-copy sheet, over-ear headphones, a brushed aluminium laptop corner, morning light through a window, cream and anthracite palette, shallow depth of field, 16:9, photorealistic"*. איורי empty-state (5): line-art מונוכרום inkblue על שקוף — חשבוניות, לידים, לקוחות, מוצרים, משימות.
- בדיקה: `airtable/show-records.sh Products` → 34 עם ImageUrl; `curl -I` על URL אחד → 200 image/webp.

### Task 4: דשבורד חכם

**Files:** `src/lib/insights.ts` + `insights.test.ts` (revenueByMonth, statusBreakdown, leadsFunnel, topCustomers, attentionItems), `src/lib/n8n-health.ts` + test (parse executions → counts), `src/components/charts/*` (RevenueBars, StatusBar, Funnel — Recharts, client), `src/components/dashboard/{brief-card,attention-list,health-strip}.tsx`, `src/app/(app)/page.tsx`, `src/app/(app)/brief/actions.ts`.

- **insights.ts (pure, tested):** `revenueByMonth(invoices, months=6)` → `[{month:'2026-04', total, count}]` כולל חודשים ריקים; `statusBreakdown(invoices)` → `[{status, count, total}]` בסדר new/validated/generated/paid/error; `leadsFunnel(leads)` → New→Contacted→Qualified (+Dead/Duplicate בנפרד); `topCustomers(invoices, customers, 5)`; `attentionItems({invoices, leads, tasks, now})` → `[{kind:'overdue'|'stale-lead'|'error'|'unpaid', title, href, severity:'red'|'amber'}]` — generated ולא paid > 14 יום = overdue; Contacted > 7 יום בלי Qualified = stale; Status error = error.
- **גרפים:** RevenueBars — עמודות inkblue, קצה מעוגל 4px, רווח 2px, ציר y מוסתר וערכים ישירים מעל עמודות (≤ 6), tooltip עם ₪ (`Money`); StatusBar — פס יחיד מחולק לפי סטטוס בצבעי LED (amber/amber/green/green/red) עם legend + מספרים; Funnel — 3 פסים אופקיים inkblue ב-3 בהירויות (ramp: 100%/70%/45% opacity) עם אחוזי המרה.
- **תקציר בוקר (AI):** server action `dailyBrief()` — `erpChat('תן תקציר בוקר קצר לבעל העסק: 3–5 שורות, מה חשוב היום, מה דורש פעולה. בלי פתיחים.', 'brief-<yyyy-mm-dd>')`; נשמר ב-`unstable_cache` עם key לפי תאריך, revalidate 6h; כפתור "רענן". כרטיס עם stagger של שורות.
- **דורש טיפול:** רשימה ממוינת לפי severity עם LED, קישור לעמוד הרלוונטי, "הכל תקין" כ-empty state עם איור.
- **בריאות המערכת:** `n8n-health.ts` קורא `GET $N8N_API_URL/executions?limit=50` (+status filter) עם `X-N8N-API-KEY`, מסכם 24 שעות: success/error, workflow אחרון שנכשל, זמן; רצועה עם 3 LED + טקסט "n8n · 12 הרצות · 0 שגיאות · לפני 2 דק׳"; אם env חסר → "לא מחובר" (ink-3). `cache: 'no-store'`, timeout 4s.
- פריסה: ledger strip (hero + count-up) → grid 12: [תקציר AI 5][דורש טיפול 4][בריאות 3] → [הכנסות 6][סטטוס+משפך 6] → [חשבוניות אחרונות 6][לקוחות מובילים 6]. Reveal stagger בכניסה.

### Task 5: שירות לקוחות באתר

**Files:** `n8n/workflows/05b-support-core.json`, עדכון `05-customer-service.json` (Telegram → Execute Workflow), עדכון `13-api.json` (rule `support` → Execute Workflow → Respond), `n8n/scripts/import-workflow.sh` (ללא שינוי), `src/lib/n8n.ts` (`erpSupport(message, sessionId)`), `src/lib/rate-limit.ts` + test, `src/lib/product-match.ts` + test, `src/app/support/page.tsx` (ציבורי), `src/app/support/actions.ts`, `src/components/chat/chat-panel.tsx` (prop `send`, `suggestions`, `persona`), `src/components/chat/support-widget.tsx` (כפתור צף + Sheet, גם ב-(app) layout), `src/proxy.ts` (allow `/support`).

- **WF5-core:** Execute Workflow Trigger (message, sessionId) → Support Agent (אותו prompt, memory customKey `support-{{sessionId}}`, knowledge_base tool) → Set reply. **WF5** הופך ל: Telegram Trigger → Set {message, sessionId: chat.id} → Execute Workflow (core) → Send Reply. **WF13:** rule `support` → Chat Input → Execute Workflow (SUPPORT_CORE) → Respond `{ok, reply}`.
- **/support:** עמוד ציבורי ממותג (לוגו, hero קטן, "שירות לקוחות איי.איי אלקטרוניקה — עונים 24/7"), צ'אט במרכז (max-w-2xl), הצעות: "מה מדיניות ההחזרות?", "יש לכם אוזניות אלחוטיות?", "כמה זמן לוקח משלוח?". `sessionId` = cookie `erp_support`. תשובה שמזכירה שמות מוצרים → `matchProducts(reply, products)` (התאמה לפי שם, case-insensitive, עד 3) → כרטיסי מוצר קטנים עם תמונה ומחיר מתחת להודעה.
- **rate-limit.ts:** `allow(key, limit=20, windowMs=60_000)` — Map בזיכרון, נבדק; `sendSupport` בודק לפי IP (`headers().get('x-forwarded-for')`), מחזיר "יותר מדי הודעות, נסה בעוד דקה".
- **Widget:** כפתור עגול 48px בפינה התחתונה-שמאלית (end) עם אייקון הודעה, פותח Sheet עם אותו ChatPanel במצב support. ב-(app) layout — כדי שהבעלים יבדוק. ב-`/support` — הצ'אט כבר במרכז, בלי widget.
- בדיקה: `n8n/scripts/api-test.sh '{"action":"support","message":"מה מדיניות ההחזרות?"}'` → תשובה מה-RAG; טלגרם עדיין עונה; Playwright: `/support` בלי login → שאלה → תשובה + כרטיס מוצר ל"אוזניות".
