# Brand Film Production Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce the 3:45 English "behind the scenes" film described in the script spec, as a rendered 1920×1080 MP4, from real captures of the running system plus motion graphics.

**Architecture:** One HyperFrames project at `film/`. `index.html` is the root timeline that mounts eleven sub-compositions (one per beat) from `film/compositions/`, plus a narration track, a music track, SFX and burned captions. Real screenshots and screen recordings live in `film/captures/` and are produced by Playwright scripts in `film/capture/` (deterministic) or by Felix (Telegram, Gmail). Animated overlays (glowing paths, node highlights, labels, counters, the architecture diagram) are HTML/CSS/GSAP drawn on top of the captures. Narration audio drives every beat's duration.

**Tech Stack:** HyperFrames 0.8.x (`npx hyperframes`), GSAP 3.14, Playwright (already in `app/` and `store/`), ElevenLabs MCP (narration, music, SFX), ffmpeg 9, Higgsfield MCP (one logo-reveal clip only).

**Spec:** `docs/superpowers/specs/2026-09-02-brand-film-script.md` (v2). Every beat number below refers to that beat sheet.

## Global Constraints

- Output 1920×1080, 30 fps, H.264 MP4, target length 3:45, hard cap 4:00.
- Palette from the admin app (`app/.interface-design/system.md`): void `#0d1017`, chassis `#161a23`, chassis-2 `#1e2330`, readout `#f3f5f9`, readout-2 `#bcc4d1`, readout-3 `#94a0b2`, signal `#5ad1ff` (glow rgba(90,209,255,.45)), LEDs green `#34d17a` / amber `#f0b429` / red `#ff5a5f`. No other hues except inside real captures.
- Fonts: Heebo 700/800 for titles, IBM Plex Sans for body, IBM Plex Mono for numbers, labels, IDs. Load from Google Fonts in the composition (allowed by HyperFrames). English captions in IBM Plex Sans 36px, always readable: 100% of screen time, never over a busy area without a scrim.
- Animation register: exaggerated is allowed (big scale pops, 3D tilts, glow trails, elastic eases), but every on-screen text stays legible and every effect explains something (spec rule "show, don't claim").
- Captures are real. No mocked UI, no fabricated rows. Hero order values (ORD number, amount, city, customer name) come from the one real order Felix places in Task 0 and are stored once in `film/data/hero-order.json`; every composition reads them from there.
- Secrets: never read `.env*`, never put API keys in the composition. Playwright capture scripts take logins from the browser session Felix creates (persistent context in `film/capture/.auth/`, git-ignored).
- Rendering gate (HyperFrames rule): `npx hyperframes check` must pass, then `npx hyperframes preview` is handed to Felix for approval before `render --quality high`.
- Commit after every task. Only commit `film/` files and this plan; other sessions work in this repo concurrently.
