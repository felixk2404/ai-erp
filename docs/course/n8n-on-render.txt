אבל עדיין, בשביל שקט תעשייתי, עדיף n8n בענן - ללקוחות הראשונים 


נכנסים ל-
https://render.com 
ופותחים חשבון חינמי. לאחר מכן ליצור Web Service חדש.

לאחר מכן יהיה לכם קישור חי: 


  



הגדרת Environment
Environment Variables. בגלל זה n8n עולה אבל לא באמת יודע איך להיפתח, ולכן את מקבלת Not Found.
בואי נוסיף אותם. תלחצי על + Add variable ותוסיפי אחד־אחד בדיוק ככה:
  
 
1
Name:
N8N_HOST
Value:
(שימי את הדומיין שלך בלי https - שימו לב זו הדוגמא של אפרת! תחליפו בדומיין שלכם)
n8n-1-zuld.onrender.com
2
Name:
N8N_PROTOCOL
Value:
https
3

Name:
WEBHOOK_URL
Value:
https://n8n-1-zuld.onrender.com
4

Name:
N8N_PORT
Value:
5678
5

Name:
N8N_EDITOR_BASE_URL
Value:
https://n8n-1-zuld.onrender.com
