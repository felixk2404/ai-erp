מדריך: יצירת חשבון GitHub והעלאת קבצים
1. יצירת חשבון GitHub
1. היכנסו ל־GitHub
2. לחצו על Sign up.
3. הזינו כתובת אימייל.
4. הגדירו סיסמה ושם משתמש.
5. אמתו את כתובת האימייל.
6. השלימו את תהליך ההרשמה.
החשבון החינמי מספיק לחלוטין לצורך יצירת repositories והעלאת קבצים.
2. יצירת Repository
לאחר ההתחברות:
1. לחצו על + בפינה העליונה.
2. בחרו New repository.
3. בשדה Repository name הזינו שם לפרויקט.
4. בחרו Public — כך הריפו תהיה ציבורית.
5. השאירו את שאר האפשרויות כברירת מחדל.
6. לחצו Create repository.
Public = כל אחד יכול לראות את הקבצים בריפו.
3. העלאת קבצים
בתוך הריפו:
1. לחצו על Add file.
2. בחרו Upload files.
3. גררו את הקבצים מהמחשב אל חלון הדפדפן.
4. בתחתית העמוד לחצו Commit changes.
5. הקבצים יופיעו כעת בתוך הריפו.
4. העלאת תיקייה שלמה
אפשר גם לגרור תיקייה שלמה לחלון ההעלאה. GitHub יעלה את הקבצים והתיקיות שבתוכה.
5. חשוב
אל תעלו לריפו ציבורית מידע רגיש כמו:
* סיסמאות
* API Keys
* Tokens
* קבצי .env
* מפתחות פרטיים
* פרטי התחברות

🖥️ התקנת GitHub Desktop ב-Windows
1. היכנס לאתר הרשמי של GitHub Desktop:
הורדת GitHub Desktop
2. לחץ על Download for Windows.
3. לאחר שהקובץ יורד, פתח אותו. ההתקנה אמורה להתחיל אוטומטית.
4. המתן לסיום ההתקנה. לאחר מכן GitHub Desktop ייפתח.
5. לחץ על Sign in to GitHub.com.
6. התחבר לחשבון ה-GitHub שלך דרך הדפדפן.
7. לאחר ההתחברות, חזור ל-GitHub Desktop — החשבון שלך אמור להיות מחובר.


📁 הורדת פרויקט מ-GitHub למחשב
אם כבר יש לך Repository ב-GitHub:
   1. פתח את GitHub Desktop.
   2. בחר File → Clone repository.
   3. בחר את ה-Repository הרצוי.
   4. בחר איפה לשמור אותו במחשב.
   5. לחץ Clone.
עכשיו הפרויקט נמצא אצלך במחשב וניתן לעבוד עליו.
אם אתה רוצה, אני יכול גם לתת לך מדריך בעברית עם תמונות: איך להוריד פרויקט מ-GitHub, לפתוח אותו ב-VS Code ולעשות Commit + Push.
